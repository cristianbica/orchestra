# Features

This unbootstrapped template contains no application feature claims. Add pages
only after inspecting the repository and identifying a concrete user-facing or
operational capability.

Rules:
- Keep each feature page short.
- Prefer linking to code locations (in the app repo) over large copy/paste.
- Mark gaps or unverified behavior explicitly; do not fill them with example
  domains from the template.
- Use `bootstrap` for initial broad context or the planless `document` workflow
  for a named target update.

Feature pages:
- Add `<slug>.md` for each main feature area.
